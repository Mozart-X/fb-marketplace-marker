# Changelog

All notable changes to Marketplace Tidy are documented here.
Format loosely follows [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] — 2026-11-01

### Added
- Per-listing **Hide** (`✕`) with a 5-second Undo toast.
- **Mark** (`🏷`) — tags a listing with a red "Marked" badge instead of hiding it.
- **Seen** tracking — auto-marked when you open a listing, toggle manually with `👁`.
  Feed display mode is configurable: Tag / Dim / Hide / Off.
- **Messaged** auto-detection — tags listings whose seller you've already messaged (amber badge).
- **Hide by seller** — a pill on any listing page blocks every listing from that seller.
- **Keyword blocking** — hide listings whose text matches your words.
- Popup dashboard with live counts and one-click Clear / Unhide / Reset.
- 100% local storage; no network calls, no tracking.
